
# StockMate

Mini Shop Inventory Management System

## Project Overview

StockMate is an Android application developed for
the Mobile Application Development Practical
assignment.

It helps small shop owners manage product inventory
using a local SQLite database.

## Technologies Used

- Android Studio
- Java
- XML
- SQLite
- RecyclerView

## Main Features

- Add new products
- View saved products using RecyclerView
- Update product details
- Delete products with confirmation
- Calculate total inventory value
- Display stock quantity and low-stock status
- Save records persistently using SQLite

## SQLite Database

Database Name: StockMate.db

Table Name: products

Columns:
- id
- name
- category
- price
- quantity

## IPO Implementation

Input:
Product name, category, price, and quantity.

Process:
Input validation, SQLite CRUD operations,
and inventory value calculation.

Output:
Product records, inventory statistics,
and stock status indicators.
